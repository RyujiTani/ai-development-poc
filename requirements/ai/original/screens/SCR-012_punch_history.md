## 概要
工場側管理者が日別・外注先別に打刻履歴を一覧確認する画面。撮影された写真のサムネイル表示を含む。
打刻修正機能への導線も提供する。

## 要件一覧

### 機能要件
| トレースID | 要件内容 | 優先度 | 備考 |
|---|---|---|---|
| SCR-012-FN-001 | 日別・外注先別に打刻履歴一覧を表示できる | High | 要件定義書 4章 |
| SCR-012-FN-002 | 日付フィルタで絞り込み検索ができる | High | 要件定義書 6章 |
| SCR-012-FN-003 | 外注先フィルタで絞り込み検索ができる | High | 要件定義書 6章 |
| SCR-012-FN-004 | 打刻履歴に紐づく撮影写真をサムネイルで表示できる | High | 要件定義書 4章 |
| SCR-012-FN-005 | サムネイルをクリック/タップして写真を拡大表示できる | Mid | [ASSUMPTION] 確認用途のため拡大表示が必要 |
| SCR-012-FN-006 | 打刻修正（工場側管理者による手動登録・修正）ができる | High | 要件定義書 4章。修正理由の入力必須 |

### UI要件
| トレースID | 要件内容 | 備考 |
|---|---|---|
| SCR-012-UI-001 | 画面上部にフィルタ条件（日付・外注先）を配置する | |
| SCR-012-UI-002 | 打刻履歴をテーブル形式で表示する（作業員名、外注先名、出勤/退勤日時、写真サムネイル） | |
| SCR-012-UI-003 | 写真サムネイルをリスト内に表示する | |
| SCR-012-UI-004 | 一覧はページネーションまたは無限スクロールで表示する | 要件定義書 6章 |
| SCR-012-UI-005 | レスポンシブWebデザインでPC/スマホ両対応とする | |

### バリデーション要件
| トレースID | 対象 | ルール |
|---|---|---|
| SCR-012-VL-001 | 日付フィルタ | 有効な日付形式であること |
| SCR-012-VL-002 | 打刻修正時の修正理由 | 必須入力。空文字の場合はエラーメッセージを表示する |
| SCR-012-VL-003 | 認証状態 | 未認証状態または管理者権限がない状態でアクセスした場合は管理者ログイン画面（SCR-010）へリダイレクトする |

### イベント・遷移要件
| トレースID | トリガー | 挙動 |
|---|---|---|
| SCR-012-EV-001 | フィルタ条件変更・検索ボタン押下 | 指定条件で打刻履歴を再取得して一覧を更新する |
| SCR-012-EV-002 | サムネイル画像クリック/タップ | モーダルまたは別画面で写真を拡大表示する |
| SCR-012-EV-003 | 打刻修正ボタン押下 | 打刻修正用の入力フォーム（モーダルまたはインライン）を表示する [ASSUMPTION] |
| SCR-012-EV-004 | 打刻修正の保存 | 修正内容を送信し、一覧を更新する |

### データ要件
| トレースID | 種別 | 内容 |
|---|---|---|
| SCR-012-DT-001 | API（取得） | GET /api/admin/punches?date={date}&contractor_id={id} — フィルタ条件に基づく打刻履歴一覧を取得する |
| SCR-012-DT-002 | API（取得） | GET /api/admin/punches/{punch_id}/photo — 署名付きURLで写真を取得する（直リンク禁止、要件定義書 7章） |
| SCR-012-DT-003 | API（送信） | PUT /api/admin/punches/{punch_id} — 打刻修正データを送信する。リクエスト: { punched_at, reason } |
| SCR-012-DT-004 | API（取得） | GET /api/admin/contractors — 外注先フィルタ用の外注先企業一覧を取得する |

## 実装・テストへの引き継ぎ指示
- コード生成時は各実装箇所のコメントに対応するトレースIDを必ず記載すること
  例: `// trace: SCR-012-FN-004`
- テスト生成時はテスト名・describeにトレースIDを含めること
  例: `describe('SCR-012-FN-002: 日付フィルタ', ...)`
- 1つの実装/テストが複数IDをカバーする場合はカンマ区切りで列挙すること

## 確認事項
- 打刻の切り捨て・切り上げルールの具体的な仕様が未定（要件定義書 3章）。
- 打刻修正時の承認フローの要否が未確定（要件定義書 3章に「工場側管理者が修正・確認可能」とあるが、承認ステップの有無）。
