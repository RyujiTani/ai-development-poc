## 概要
工場側管理者がシステムのユーザーアカウント（工場側管理者アカウント、外注先管理者アカウント）を登録・管理する画面。
外注先管理者アカウントの発行もこの画面から行う。

## 要件一覧

### 機能要件
| トレースID | 要件内容 | 優先度 | 備考 |
|---|---|---|---|
| SCR-015-FN-001 | 登録済みのユーザーアカウント一覧を表示できる | High | 要件定義書 4章「ユーザー（管理者）管理」 |
| SCR-015-FN-002 | 工場側管理者アカウントを新規登録できる | High | |
| SCR-015-FN-003 | 外注先管理者アカウントを新規発行できる | High | 要件定義書 3章「外注先管理者アカウントを登録する」 |
| SCR-015-FN-004 | 既存のユーザーアカウント情報を編集できる | High | [ASSUMPTION] |
| SCR-015-FN-005 | ユーザーアカウントを削除（無効化）できる | Mid | [ASSUMPTION] |

### UI要件
| トレースID | 要件内容 | 備考 |
|---|---|---|
| SCR-015-UI-001 | ユーザーアカウントをリスト/テーブル形式で表示する（ユーザー名、権限種別、所属外注先企業等） | |
| SCR-015-UI-002 | 「新規登録」ボタンをリスト上部に配置する | |
| SCR-015-UI-003 | 各ユーザー行に「編集」「削除」の操作ボタンを配置する | |
| SCR-015-UI-004 | 新規登録・編集時はモーダルまたはインラインフォームで入力欄を表示する | [ASSUMPTION] |
| SCR-015-UI-005 | 一覧はページネーションまたは無限スクロールで表示する | 要件定義書 6章 |
| SCR-015-UI-006 | レスポンシブWebデザインでPC/スマホ両対応とする | |

### バリデーション要件
| トレースID | 対象 | ルール |
|---|---|---|
| SCR-015-VL-001 | ユーザーID | 必須入力。空文字の場合はエラーメッセージを表示する。既存IDとの重複不可 |
| SCR-015-VL-002 | パスワード | 必須入力（新規登録時）。セキュリティ要件に準拠した強度であること [ASSUMPTION] |
| SCR-015-VL-003 | 権限種別 | 必須選択（工場側管理者/外注先管理者のいずれか） |
| SCR-015-VL-004 | 所属外注先企業 | 外注先管理者の場合は必須選択。紐づく外注先企業を選択すること |
| SCR-015-VL-005 | 削除操作 | 削除前に確認ダイアログを表示する [ASSUMPTION] |
| SCR-015-VL-006 | 認証状態 | 未認証状態または管理者権限がない状態でアクセスした場合は管理者ログイン画面（SCR-010）へリダイレクトする |

### イベント・遷移要件
| トレースID | トリガー | 挙動 |
|---|---|---|
| SCR-015-EV-001 | 「新規登録」ボタン押下 | ユーザーアカウント情報の入力フォームを表示する |
| SCR-015-EV-002 | 登録/更新フォームの「保存」ボタン押下かつバリデーション成功 | ユーザーアカウントを登録/更新し、一覧を更新する |
| SCR-015-EV-003 | 「編集」ボタン押下 | 該当ユーザーの情報を入力フォームにロードして表示する |
| SCR-015-EV-004 | 「削除」ボタン押下かつ確認OK | 該当ユーザーアカウントを削除（無効化）し、一覧を更新する |
| SCR-015-EV-005 | 権限種別で「外注先管理者」を選択 | 所属外注先企業の選択欄を表示する |

### データ要件
| トレースID | 種別 | 内容 |
|---|---|---|
| SCR-015-DT-001 | API（取得） | GET /api/admin/users — ユーザーアカウント一覧を取得する |
| SCR-015-DT-002 | API（登録） | POST /api/admin/users — ユーザーアカウントを新規登録する。リクエスト: { user_id, password, role, contractor_id? } |
| SCR-015-DT-003 | API（更新） | PUT /api/admin/users/{user_id} — ユーザーアカウント情報を更新する |
| SCR-015-DT-004 | API（削除） | DELETE /api/admin/users/{user_id} — ユーザーアカウントを削除する |
| SCR-015-DT-005 | API（取得） | GET /api/admin/contractors — 外注先企業選択用のプルダウンデータを取得する |

## 実装・テストへの引き継ぎ指示
- コード生成時は各実装箇所のコメントに対応するトレースIDを必ず記載すること
  例: `// trace: SCR-015-FN-003`
- テスト生成時はテスト名・describeにトレースIDを含めること
  例: `describe('SCR-015-VL-004: 外注先管理者の所属企業必須選択', ...)`
- 1つの実装/テストが複数IDをカバーする場合はカンマ区切りで列挙すること

## 確認事項
- 初期パスワードの発行方法（自動生成、管理者が手動設定、メール通知等）が未定。
- 自分自身のアカウントを削除できないようにする制御の要否が未定。
