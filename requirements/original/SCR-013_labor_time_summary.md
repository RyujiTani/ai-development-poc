## 概要
工場側管理者が作業員ごとの実労働時間を期間指定（日次・月次）で集計し確認する画面。
集計結果のCSVダウンロード機能を備える。

## 要件一覧

### 機能要件
| トレースID | 要件内容 | 優先度 | 備考 |
|---|---|---|---|
| SCR-013-FN-001 | 作業員ごとの実労働時間を日次で集計表示できる | High | 要件定義書 4章 |
| SCR-013-FN-002 | 作業員ごとの実労働時間を月次で集計表示できる | High | 要件定義書 4章 |
| SCR-013-FN-003 | 集計期間を指定できる | High | 要件定義書 6章「期間指定集計」 |
| SCR-013-FN-004 | 集計結果をCSVファイルでダウンロードできる | High | 要件定義書 4章。給与計算処理は対象外のため、外部ソフト連携用データ出力 |

### UI要件
| トレースID | 要件内容 | 備考 |
|---|---|---|
| SCR-013-UI-001 | 画面上部に期間指定（開始日・終了日）と集計単位（日次/月次）の選択欄を配置する | |
| SCR-013-UI-002 | 集計結果をテーブル形式で表示する（作業員名、外注先名、日付、労働時間等） | |
| SCR-013-UI-003 | CSVダウンロードボタンを配置する | |
| SCR-013-UI-004 | 一覧はページネーションまたは無限スクロールで表示する | 要件定義書 6章 |
| SCR-013-UI-005 | レスポンシブWebデザインでPC/スマホ両対応とする | |

### バリデーション要件
| トレースID | 対象 | ルール |
|---|---|---|
| SCR-013-VL-001 | 期間指定（開始日） | 必須入力。有効な日付形式であること |
| SCR-013-VL-002 | 期間指定（終了日） | 必須入力。有効な日付形式であること。開始日以降であること |
| SCR-013-VL-003 | 認証状態 | 未認証状態または管理者権限がない状態でアクセスした場合は管理者ログイン画面（SCR-010）へリダイレクトする |

### イベント・遷移要件
| トレースID | トリガー | 挙動 |
|---|---|---|
| SCR-013-EV-001 | 期間指定・集計単位選択後「集計」ボタン押下 | 指定条件で労働時間を集計して一覧を更新する |
| SCR-013-EV-002 | 「CSVダウンロード」ボタン押下 | 現在の集計結果をCSVファイルとしてダウンロードする |

### データ要件
| トレースID | 種別 | 内容 |
|---|---|---|
| SCR-013-DT-001 | API（取得） | GET /api/admin/labor-summary?start_date={date}&end_date={date}&unit={daily/monthly} — 集計結果を取得する |
| SCR-013-DT-002 | API（取得） | GET /api/admin/labor-summary/csv?start_date={date}&end_date={date}&unit={daily/monthly} — CSV形式で集計結果をダウンロードする |

## 実装・テストへの引き継ぎ指示
- コード生成時は各実装箇所のコメントに対応するトレースIDを必ず記載すること
  例: `// trace: SCR-013-FN-004`
- テスト生成時はテスト名・describeにトレースIDを含めること
  例: `describe('SCR-013-FN-004: CSVダウンロード', ...)`
- 1つの実装/テストが複数IDをカバーする場合はカンマ区切りで列挙すること

## 確認事項
- 労働時間の自動計算ロジック（打刻の切り捨て・切り上げルール）が未定。
- CSV出力のカラム定義・フォーマットが未定。
- 外注先別の絞り込み機能が必要かどうかの確認が必要。[ASSUMPTION] 全外注先を一括表示とする。
