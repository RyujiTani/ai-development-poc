## 概要
外注先管理者が打刻対象の作業員を一覧から選択する画面。チェックボックスによる一括選択が可能。
選択された打刻モード（出勤/退勤）が画面上部に表示される。

## 要件一覧

### 機能要件
| トレースID | 要件内容 | 優先度 | 備考 |
|---|---|---|---|
| SCR-004-FN-001 | ログイン中の外注先管理者の所属企業に紐づく作業員一覧を表示できる | High | |
| SCR-004-FN-002 | 作業員をチェックボックスで個別に選択できる | High | |
| SCR-004-FN-003 | 全作業員を一括選択/一括解除できる | High | 要件定義書 6章「一括チェックボックス選択」 |

### UI要件
| トレースID | 要件内容 | 備考 |
|---|---|---|
| SCR-004-UI-001 | 作業員をチェックボックス付きリストで表示する | |
| SCR-004-UI-002 | 全選択/全解除のチェックボックスをリスト上部に配置する | |
| SCR-004-UI-003 | 選択中の打刻モード（出勤/退勤）を画面上部に明示する | |
| SCR-004-UI-004 | レスポンシブWebデザインでPC/スマホ両対応とする | |
| SCR-004-UI-005 | スマホ利用時はボタン・チェックボックスを大きくタップしやすいUIとする | 屋外操作を考慮 |
| SCR-004-UI-006 | 一覧はページネーションまたは無限スクロールで表示する | 要件定義書 6章 |

### バリデーション要件
| トレースID | 対象 | ルール |
|---|---|---|
| SCR-004-VL-001 | 選択状態 | 1名以上の作業員が選択されていない場合は次へ進めない（エラーメッセージを表示する） |
| SCR-004-VL-002 | 認証状態 | 未認証状態でアクセスした場合はログイン画面（SCR-001）へリダイレクトする |

### イベント・遷移要件
| トレースID | トリガー | 挙動 |
|---|---|---|
| SCR-004-EV-001 | 「次へ」ボタン押下かつ1名以上選択済 | 選択された作業員リストと打刻モードを保持して撮影・送信画面（SCR-005）へ遷移する |
| SCR-004-EV-002 | 戻るボタン押下 | 打刻モード選択画面（SCR-003）へ遷移する |

### データ要件
| トレースID | 種別 | 内容 |
|---|---|---|
| SCR-004-DT-001 | API（取得） | GET /api/workers — ログインユーザーの所属企業に紐づく作業員一覧を取得する |
| SCR-004-DT-002 | 状態保持 | 選択された作業員IDリストと打刻モードを後続画面に引き継ぐ |

## 実装・テストへの引き継ぎ指示
- コード生成時は各実装箇所のコメントに対応するトレースIDを必ず記載すること
  例: `// trace: SCR-004-FN-003`
- テスト生成時はテスト名・describeにトレースIDを含めること
  例: `describe('SCR-004-VL-001: 作業員未選択時バリデーション', ...)`
- 1つの実装/テストが複数IDをカバーする場合はカンマ区切りで列挙すること

## 確認事項
- 作業員リストの表示順（氏名五十音順、登録順など）の仕様が未定。
- 既に当日の出勤打刻済みの作業員をリスト上でどう表示するか（グレーアウト、打刻済みマーク等）が未定。
